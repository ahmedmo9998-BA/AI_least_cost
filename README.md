# AI Least-Cost Path Finder

An AI search project implementing least-cost path finding (e.g. Uniform Cost Search / graph search algorithms) over a problem case, deployed as an interactive web app.

## Overview
This project solves a least-cost pathfinding problem using classic AI search algorithms, worked through in `case 2 ai.ipynb`.

## Live App
🔗 https://pathfinder-pal-83.lovable.app

## Tech Stack
- Python
- Graph/search algorithms (e.g. Uniform Cost Search, Dijkstra-style search)
- Jupyter Notebook

## How to Run
```bash
git clone https://github.com/bebo99-BA/AI_least_cost.git
cd AI_least_cost
pip install jupyter
jupyter notebook "case 2 ai.ipynb"
```
